# مسجل الشاشة الخفيف

برنامج تسجيل شاشة بسيط جدًا لويندوز، مناسب للأجهزة الضعيفة. التسجيل نفسه بيتم عن طريق `ffmpeg`.

## المميزات

- زر واحد للبدء والإيقاف، واختصار **F9** من أي مكان.
- شريط صغير عائم أثناء التسجيل فيه الوقت وزر الإيقاف، ومش بيظهر في الفيديو (ويندوز 10 إصدار 2004 وأحدث).
- اختيار الوضوح (720p / 1080p / الأصلي)، والفريمات (10 لـ 60)، والجودة (CRF 34 لـ 18). البرنامج بيفتكر آخر اختيار.
- صوت الميكروفون (أول ميكروفون موجود).
- التقاط الشاشة بكارت الشاشة (`ddagrab`) عشان الماوس يبقى ناعم، ولو مش مدعوم بيرجع لـ `gdigrab`.
- التسجيل بيتم بصيغة MKV عشان يفضل سليم لو البرنامج أو الجهاز وقع، وبعد الإيقاف بيتحوّل لـ MP4 من غير إعادة ضغط.
- الفيديوهات بتتحفظ في `Videos\ScreenRecords`.

## التشغيل من الكود

محتاج Python 3 و `ffmpeg.exe` (جنب `recorder.pyw` أو في الـ PATH):

```
pythonw recorder.pyw
```

أو شغّل `Start Recorder.bat`.

## عمل نسخة exe للتوزيع

محتاج PyInstaller (`pip install pyinstaller`) و `ffmpeg.exe` في الـ PATH أو جنب `build.bat`:

```
build.bat
```

الناتج: فولدر `dist\ScreenRecorder` فيه `ScreenRecorder.exe` ومعاه ffmpeg، و `ScreenRecorder.zip` جاهز للإرسال.
الشخص التاني يفك الضغط ويشغّل `ScreenRecorder.exe` من غير ما يسطّب حاجة.
